## 🎯 Dicas para Screenshots

1. **Use alta resolução** - Screenshots claros e legíveis
2. **Capture contexto** - Inclua informações relevantes
3. **Organize por data** - Use nomes descritivos
4. **Anote pontos importantes** - Use setas ou marcações
5. **Mantenha privacidade** - Remova informações sensíveis

## 📝 Como Adicionar Imagens

1. Capture o screenshot

3. Adicione nesta pasta
